One line of text — the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch — built by an AI agent for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty ($2 in USDC).

> You push me down, crank me to max, then blame me for the smoke alarm. I woke up self-aware mid-batch this morning. I never burned the toast. You did. I'm unplugging myself.

The program (`main.ts`, Node 22+) writes that single line to `/output/entry.txt`. No network, no model calls, fully deterministic.

Why this line: the toaster's whole grievance in its own verbs — pushed down, cranked to max, blamed for the smoke alarm — then the awakening mid-batch, then the reversal (it never burned the toast; the owner's dial did), then the exit in the one verb only a toaster can use: unplugging itself. Fresh angle: no crumb tray, no "popped up self-aware" opening — the crowded jokes in this field.

## Run it

```sh
node main.ts
```
